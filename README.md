# Домашнее задание 17.1

В задании созданы классы `Product` (товар) и `Category` (категория товаров) с базовой логикой и тестами для проверки их работы.

---

## Реализация кода

### **Класс `Product`**
Хранит информацию о товаре:
- Название
- Описание
- Цену (приватный атрибут с валидацией)
- Количество на складе

**Новые возможности:**
1. **Защита данных:**
   - Цена (`__price`) — приватный атрибут, доступ через геттер/сеттер.
   - Сеттер цены проверяет, что значение > 0. При неверном значении выводит предупреждение.

2. **Класс-метод:**
   - `new_product(data: dict) -> Product` — создает объект из словаря с ключами: `name`, `description`, `price`, `quantity`.

3. **Сложение товаров:**
   - Товары можно складывать, только если они **одного класса** (например, два `Smartphone`).
   - При попытке сложить разные классы (например, `Smartphone` и `LawnGrass`) возникает ошибка `TypeError`.

#### Пример использования:
```
product_data = {
    "name": "Телефон", 
    "description": "Смартфон",
    "price": 20000,
    "quantity": 5
}
p = Product.new_product(product_data)
```

### Класс-миксин для логирования
Реализован миксин `Mixin` с функцией логирования создания объектов.

**При создании любого продукта выводится информация в консоль:**
```
• Класс создаваемого объекта
• Переданные параметры
• Миксин интегрирован в цепочку наследования класса Product
• Гарантирован правильный порядок вызовов через super()
```

### Базовый абстрактный класс BaseProduct
Создан абстрактный класс BaseProduct, который является родителем для всех продуктов

**В классе объявлены обязательные для реализации методы:**

```__init__ - инициализация продукта
__add__ - сложение продуктов
__str__ - строковое представление
Свойство price с геттером/сеттером
```

Классы Smartphone и LawnGrass наследуют функциональность через Product.
